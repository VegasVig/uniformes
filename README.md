# 👕 Sistema de Uniformes

Sistema web desenvolvido para automatizar e organizar os pedidos de uniformes dos colaboradores da empresa.

A aplicação permite que o funcionário selecione os itens desejados, assine digitalmente diretamente na tela e envie a solicitação. Após o envio, o sistema gera automaticamente um recibo em PDF como comprovante do pedido.

## 🚀 Funcionalidades

✅ Seleção de uniformes disponíveis para solicitação  
✅ Preenchimento de dados do colaborador  
✅ Assinatura digital diretamente na tela via Canvas  
✅ Envio automático das informações para o Google Sheets  
✅ Geração automática de recibo em PDF  
✅ Interface responsiva para desktop e celular  
✅ Organização e rastreabilidade dos pedidos  

---

## 🛠 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Google Sheets (armazenamento de dados)  
- Google Apps Script (automação e integração)  
- Canvas API (captura de assinatura)  
- Geração de PDF  

---

## 🎯 Objetivo do Projeto

O objetivo deste sistema é reduzir processos manuais no controle de uniformes, evitando erros em solicitações e melhorando a organização interna da empresa.

Antes do sistema, os pedidos eram feitos manualmente.  
Com a automação:

✔️ O processo ficou mais rápido  
✔️ Houve maior controle e rastreabilidade  
✔️ O colaborador recebe comprovante imediato do pedido
